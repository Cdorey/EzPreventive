# EzNutrition 2.2.0.0

产品版本：`2.2.0.0`。主线：`master`。Git 附注标签：`v2.2.0.0`，指向本次发布的主线合并提交。

## 主要变化

- **报告签发与打印**：NRS 2002、MNA-SF、MUST、膳食调查、能量核算和 SOAP 接入审核签发、更正、固定 PDF 归档及原件重印。签发和打印分别授权；评估稿带用途水印。报告处理在 Blazor 与本机宿主内完成。
- **报告内容**：膳食报告支持食材贡献排名与独立 DRIs 参考节配置；能量报告支持总能量、分配及交换份节段选择；SOAP 保留四节标题、原文换行与空白正文。量表及 DRIs 独立速查支持评估稿打印。
- **档案与复诊**：档案搜索、最近更新列表、复诊入口和按需读取的多期历史；报告包保留修订链与历史 PDF，保存时执行原子条件提交。
- **认证会话**：轮换刷新凭据、会话撤销、浏览器与桌面的会话恢复及跨窗口协调。公共系统信息与认证入口分离。
- **注册与权限管理**：用户名格式校验、重复邮箱和确认邮件拒收提示；角色声明变更与成员资料校验解耦。
- **维护管理**：数据库持久化运行设置、站点维护页面、可预览的账号清理，以及每日账号、过期资质申请、LLM 审计和孤立文件维护。

## 升级要求

本次包含接口契约变更。部署时按[HTTP API 2.2 升级说明](./http-api/README.md#从-21-升级)协调升级服务端、浏览器客户端和 WPF 客户端，并应用相应数据库迁移。认证配置与迁移步骤见[认证会话说明](./authentication-sessions.md)，维护配置见[文档目录](./README.md)。

`IssueReport` 与 `PrintReport` 通过现有账号或角色 Claims 管理入口显式配置，操作与备份说明见[报告使用说明](./report-user-guide.md)。旧重复邮箱账号的登录限制见[已知限制](./authentication-sessions.md#已知限制旧账号的重复邮箱)。

## 验证与实施范围

报告的自动测试、浏览器签发与重印、PDF 内容及分页、WPF 验证记录见[报告验收审计](./report-acceptance-audit.md)。独立作废、历史标记副本、正式报告删除、咨询总报告和 AI 正文报告仍按该文档记录的范围处理。

本标签用于固定发布源码；生产部署、数据库迁移及安装包分发由部署流程执行。
